JS Gamer Audio (Android) - Chip-X / JS SoftTools

BUILD THE APK (free, no Android Studio needed)
1. Create a new GitHub repo (e.g. js-gamer-audio) and upload ALL files of this folder
   (keep the .github folder).
2. Open the repo > Actions tab > "Build APK" > Run workflow (it also runs on every push).
3. When it turns green, open the run > Artifacts > download JS-Gamer-Audio-APK.
4. Unzip, copy app-debug.apk to the phone, allow "install unknown apps", install.

OR with Android Studio: File > Open this folder > Build > Build APK(s).

USE
- Game Sound Booster: Start boost, play your game. Raise the slider slowly.
- Voice Studio: wear headphones, pick a voice, Start live voice.
